Drowsy Bot Command Reference

Commands only: what each bot command does.

This PDF covers the bot commands users and staff can run in Discord. Slash commands use the / menu. Legacy text commands begin with !. Staff-only commands require a staff role in the server.

How To Read This

  • Public commands can be used by regular members.
  • Staff Only commands are limited to moderators or event staff.
  • Queue commands control live stage or open-mic sessions.
  • Ad and invite tools support overlays and moderation.

Slash Commands

Discord app commands
/eventsPublic

Posts links for live and upcoming Discord scheduled events in the server.

/queuePublic

Shows the current lineup and active stage status for the server.

/announceStaff Only

Sends an announcement through the bot to the current channel or another selected text channel.

Options: message, optional title, optional color, optional target channel.

/announce-colorStaff Only

Sets, checks, or clears the default embed color used for announcements in that server.

Options: color and optional reset flag.

/start-queue/startqueueStaff Only

Starts queue tracking for the voice or stage channel the staff member is currently in and posts the control panel.

/open-queueStaff Only

Reopens the active queue so new people can join the lineup again.

/close-queueStaff Only

Closes the active queue to new joiners without ending the current event.

/nextStaff Only

Moves the session forward to the next performer in the queue.

/radioStaff Only

Starts or stops the intermission radio used between performers.

/stop-queueStaff Only

Ends the active event, closes the session, and posts event stats when available.

/ad-uploadStaff Only

Uploads a new image ad for the OBS overlay and makes it the active ad.

Options: required image attachment, optional title.

/ad-listStaff Only

Lists the uploaded ads so staff can see their ad numbers and current order.

/ad-showStaff Only

Switches the active overlay ad to a specific uploaded ad by its list number.

Option: index from the ad list.

/ad-rotateStaff Only

Turns on automatic ad rotation for the OBS overlay.

Option: seconds between changes.

/ad-rotate-stopStaff Only

Turns off automatic ad rotation and leaves the current ad in place.

/ad-removeStaff Only

Deletes an uploaded ad image by its list number.

Option: index from the ad list.

/allow-invitesStaff Only

Lets a specific user or bot post Discord invite links without being moderated.

Option: target user or bot.

/revoke-invitesStaff Only

Removes invite-link permission from a user or bot on the allowlist.

Option: target user or bot.

/purge-invitesStaff Only

Scans text channels and deletes unauthorized Discord invite links.

Option: messages per channel to scan.

Legacy Text Commands

Message commands that begin with !
!queue!qPublic

Replies with the current queue embed for the active stage.

!queuejoin!qjPublic

Joins the active lineup if the queue is open and the member is in the required voice channel.

!queueleave!qlPublic

Leaves the current queue. If the current performer leaves, the queue advances forward.

!queuenext!qnStaff Only

Advances to the next performer using the message-command version of the queue controls.

!addqueue!aqStaff Only

Adds a user to the lineup by mention, user ID, exact username, or exact display name.

!startqueue!sqStaff Only

Starts the active queue for the voice or stage channel the staff member is currently connected to and posts the control panel.

!endqueue!eqStaff Only

Ends the active queue session, closes the connection, and posts event stats when available.

!stagestart!ssStaff Only

Starts tracking a Discord stage channel the staff member is already connected to.

!stageend!seStaff Only

Stops stage tracking that was started with the legacy text command flow.

Notes

Important behavior
  • Queue commands only work when there is an active tracked stage or voice session.
  • Some commands return private staff replies instead of public messages.
  • Advertisement commands affect the OBS/browser overlay assets used by the bot.
  • Invite moderation commands manage an allowlist and cleanup unauthorized invite links.
